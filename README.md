## Project

AkiraForge is a modular, open-source multi-agent anime studio engine that turns a structured creative brief into progressive, inspectable film packages in the aesthetic of 1988 Japanese hand-drawn theatrical anime (technique and quality bar inspired by that era's densest cyberpunk cinema - style approximation only; no training on copyrighted frames without license).

PROBLEM
Theatrical anime features still cost millions and require closed studio pipelines. Independent creators with strong stories cannot access that ceiling. Existing AI video tools drift identity, break continuity over minutes, and rarely expose intermediate assets for audit or fork. There is no community-owned engine that mirrors a real theatrical anime production hierarchy with hard quality gates from 30-second proofs to feature-length paths.

SOLUTION
Build a hierarchical multi-agent studio (Director, Scriptwriter, Character Consistency Lock, Storyboard/Layout, Key Animator, Inbetweener, Background, FX, Color, Compositor, Sound/Composer, Voice, multi-level QA Critics) that:
- Produces true 2D cel look-and-feel: precise linework, multi-layer cels, limited-but-expressive timing, multiplane parallax, mechanical backgrounds, explosive FX, speed lines, film grain, 1980s color timing.
- Locks character identity and temporal coherence across shots and long sequences.
- Ships full packages: screenplay, boards, model sheets, keys/inbetweens, backgrounds, FX, color, compositing, score in Geinoh Yamashirogumi spirit, JP + EN voice options with lip-sync, subtitles, and all intermediate assets under open licenses.
- Proves itself on short high-fidelity clips before OVA-scale and feature paths.

WHY HIERARCHY HELPS
No single contributor builds a feature engine. Leaves are independently claimable (style bible, SOTA survey, legal rails, agent schemas, consistency pipelines, audio modules, eval harnesses, short demos). Peer review merges only verified MIT/CC work into a living orchestrator. Public ledgers track labor and capital.

IN SCOPE
- Open software (MIT or Apache-2.0), docs and creative style guides (CC-BY-4.0 where appropriate)
- Progressive milestones: 20-60s consistent clips -> 3-5 min narrative shorts -> 15-25 min OVA-scale experiments -> documented costed feature path
- Style approximation and technique analysis; synthetic + public-domain + artist-contributed datasets preferred
- Modular pipelines (ComfyUI nodes, LangGraph/equivalent) so stages version independently

OUT OF SCOPE
- Training on copyrighted anime frames without explicit license
- Cloning named commercial titles or characters as output
- One-click "feature tomorrow" marketing claims without progressive gates
- Collecting user API keys on the public project board
- Malware, unauthorized access tooling, or dual-use attack kits

SUCCESS
Success is not a single click. Success is a living, community-owned engine that demonstrably raises the independent creator ceiling: open evals, short demos with full intermediate assets, and a honest 2026-2028 path to 90-120 minute theatrical packages.

COMPLEMENTS
Complements local personal anime studio pipelines and generic video generators; unique gap is open hierarchical studio orchestration + 1988 hand-drawn quality bar + claimable progressive proof chain under public peer review.
